## Project Overview
The **Student Grade Calculator** is a Python CLI program designed to calculate students' academic grades using standard weighted evaluation components.

## Features
- Interactive terminal input
- Weighted score computation (Quizzes 25%, Assignments 15%, Midterm 30%, Final Exam 30%)
- Clean console summary

## How to Run
```bash
python grade_calculator.py
```
